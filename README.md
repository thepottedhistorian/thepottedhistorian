# Hi there 👋 I'm Rebecca

**Support Analyst by day, digital archivist by night, plant hoarder by weekend.**

My work spans enterprise technical support, custom Python and Google Apps Script development, digital webministry, and historical botanical research. Whether I'm designing SQLite-backed specimen trackers, deploying automated data pipelines, or cataloging pre-17th-century herbal literature, I specialize in building tools that bring order to complex datasets. I apply the same logic to cultivating rare orchids—though it's the only hobby where "debugging" literally means picking off insects, and the plants are significantly less cooperative than the code.
